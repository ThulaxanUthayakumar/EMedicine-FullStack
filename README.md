# E-Medicine Management System

A full-stack web application designed to streamline online medicine management, user authentication, and order processing.

## Tech Stack
- **Frontend:** React.js, JavaScript
- **Backend:** ASP.NET Core Web API, C#
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Core
- **Security:** JWT Authentication, Role-Based Authorization

## Key Features
- Admin and User Authentication
- Medicine Management (CRUD Operations)
- Medicine Search and Browsing
- Shopping Cart Management
- Order Placement and Management
- Role-Based Access Control
- RESTful API Integration

## Getting Started

**Backend**
```bash
cd backend
dotnet restore
dotnet ef database update
dotnet run
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```

Configure the SQL Server connection string and JWT settings before running the application.
